# どれトク？ふくおかの定期（commupass_fukuoka）

福岡市内の鉄道で通勤する人が「定期券をどう買えば一番お得か」を判定する PWA。
駅の選択は路線別に色分け。ヘッダーは福岡の街（タワー・天神ビル・ドーム・電車・那珂川）の実写コラージュ、
配色は博多織インスパイアの紅・藍・金茶。

## できること

1. **定期券の構成** — 出発駅・到着駅を選ぶと経路と乗換駅を判定し、
   単独定期／連絡定期（1枚化）／分割定期などの買い方候補を総額の安い順に提示。
   乗換駅が複数ありうる場合は **経由駅** を指定して構成を固定できる（例：西鉄→地下鉄を天神で乗り換えるか薬院か）。
   「路線図をひらく」ボタンで福岡全体の路線図（SVG・拡大縮小・ドラッグ移動・選択駅ハイライト）を表示。
   - 地下鉄⇔JR筑肥線（姪浜直通）、地下鉄⇔JR鹿児島本線（博多）、
     天神大牟田線⇔地下鉄（天神・薬院）、貝塚線⇔地下鉄（貝塚）の連絡定期に対応。
   - 3社（西鉄〜地下鉄〜JR/貝塚線）通しの連絡定期は発売されないため分割になる旨も表示。
2. **月ごとの損得** — その月の出勤日数から「1ヶ月定期 vs IC都度払い」の損益分岐を月別に表示。
   連休の多い月・長期休暇のある月は 1ヶ月定期が割高になることが分かる。
3. **会社の休日設定** — 完全週休2日＋祝日／土日のみ／日曜のみ／土曜出勤あり／シフト制／
   カスタム（休む曜日＋会社の年間休業日）に対応。土曜出勤は「第2・4週」「第1・3・5週」「毎週」から選択。
   有給・在宅・出張・夏季休暇なども差し引ける。
4. **6ヶ月／3ヶ月／1ヶ月／ハイブリッド／IC の総額比較** — 対象期間（6〜24ヶ月）の総コストを比較。
5. **途中下車などのイレギュラー** — 定期区間外の駅にたまに寄る場合の
   「乗り越し精算 vs 定期延長 vs 1日券」を比較し、何回以上で延長が得かの閾値を提示。
6. **払戻し概算** — 転勤・退職で解約したときの払戻額の目安。
7. 結果を **PDF** で保存。オフライン動作（PWA）。

## 構成

```
index.html
css/styles.css

js/app.js      経路探索・構成候補・出勤日数エンジン・戦略比較・途中下車・払戻し・色分けドロップダウン・UI
js/lib/        jsPDF, html2canvas（同梱・オフラインPDF用）

docs/参考リンク.txt   参照した各社公式ページ
```

## データについて

運賃・定期額は改定されます。`js/data.js` の `FARE_TABLE` は
駅探 / NAVITIME / 各社公式（2026年9月時点）を参照した **初期めやす**で、
`src` に出典を記録しています。「めやす／要確認」の付いた値は特に各社公式で確認してください。
アプリ内でも各区間の額は手入力で上書きでき、入力はブラウザに保存されます。

表に無い区間は、1ヶ月定期額を入れれば `DISCOUNT_MODEL` で3/6ヶ月を概算します。

最終確認は各社の公式運賃検索・窓口で。

## 開発メモ

- 依存なしの単一構成。ビルド不要。`ローカルサーバー起動.cmd` でローカル確認。
- 計算エンジンは Python 移植版（`scratchpad/verify.py` 相当）と headless Chrome で検証済み。
